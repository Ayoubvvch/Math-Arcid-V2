نواة الرياضيات: البقاء بالمعادلات

لعبة ساندبوكس وبقاء ثنائية الأبعاد تدعم يد التحكم (Controller) والتعديل الحر

1. طابق قيمة X للنجاة!

كل وحش يحمل معادلة (مثلاً 3 + 2). عدّل قيمة X لديك لتصبح 5 عبر الأزرار الأربعة، وستنطلق **صاعقة نيون تلقائية** تدمره فوراً!

2. ابنِ أبراجاً رياضية

اجمع **بلورات الطاقة** وابنِ أبراج الأعداد الزوجية (2n)، وأبراج الأعداد الفردية (2n+1)، ووشائع القواسم (3n) للدفاع عن قاعدتك.

3. عدّل قوانين اللعبة

افتح **محرر الساندبوكس** في أي لحظة لتغيير العمليات الحسابية للأزرار، أو تفعيل الموارد اللانهائية، أو تعديل سرعة اللعبة كما تشاء.

خريطة التحكم الكاملة (يد التحكم Controller + لوحة المفاتيح والفأرة)

الحركة في العالم Left Stick / WASD / الأسهم
تغيير قيمة X (الأزرار الـ 4) A, B, X, Y / [1, 2, 3, 4]
إطلاق الصاعقة / طلقات الدفع RT / Space / كليك يسار
بناء البرج المختار في الشبكة LT / [F] / كليك يمين
تبديل نوع المبنى الهندسي LB, RB / [Q, E]
زيادة/إنقاص X سريعاً D-Pad Up/Down / عجلة الفأرة
