      🚀 How to Add a New Math Game

      This repository is engineered to be infinitely extensible with zero build configurations:

      Step 1: Create Game Directory

      Create a dedicated folder inside games/<your-game-slug>/ containing:

      • index.html (Entry point / game canvas)
      • style.css (Game specific styles)
      • js/ (Modular ES6 game code, or standalone script)

      Step 2: Register in games.json

      Add an entry into games.json with the game's metadata:

      {
  "id": "my-game",
  "title": "My Calculus Game",
  "slug": "my-game",
  "category": "Calculus",
  "difficulty": "Intermediate",
  "difficultyLevel": 2,
  "description": "Short description...",
  "mathConcepts": ["Concept 1", "Concept 2"],
  "controls": ["Key A: Action 1"],
  "path": "games/my-game/index.html",
  "status": "ready"
}

      Step 3: Leverage Shared Utilities & Gamepad

      Import from ../../shared/:

      • gamepad.js for PlayStation (✕, ◯, ▢, △) & Xbox gamepad input with dual haptics
      • math-engine.js for Vector2D and differentiation operators
      • canvas-kit.js for Retina HiDPI and zero-GC particle pools
      • retro-audio.js for synthesized audio feedback without MP3 assets
